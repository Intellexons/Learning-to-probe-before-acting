\noindent\textbf{What this is.}
A dated log of experiments run on the LoRA4VR multi-turn RL loop. Each entry
records what was tried, what happened, and how to reproduce it. Entries are
added as experiments complete. Reproduction references a git commit; the code
at that commit is the exact code that produced the result.

\noindent\textbf{System.} \texttt{Qwen3-4B-Instruct-2507} with a LoRA adapter
trained by branched multi-turn GRPO (\texttt{src/branched\_trainer.py}). The
model writes \texttt{policy(state) -> action} Python for the slosh-tank
environment (\texttt{scripts/seed\_tasks/slosh\_tank\_env.py}); the policy is
scored in a sandboxed subprocess. Method and experimental design:
\texttt{docs/paper.tex}.
